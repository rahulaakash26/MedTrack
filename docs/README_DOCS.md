## 🎯 Quick Reference

### Important URLs (Local Development)
```
Main App: http://localhost:5500/
Login: http://localhost:5500/auth/login.html
Signup: http://localhost:5500/auth/signup.html
```

### Important Paths
```
HTML: /index.html, /auth/*.html
CSS: /assets/css/*.css
JS: /assets/js/*.js
Images: /assets/images/*.svg
Config: /config/config.js
```

### Configuration Files
```
Supabase Config: config/config.js
Example Template: config/config.example.js
```
